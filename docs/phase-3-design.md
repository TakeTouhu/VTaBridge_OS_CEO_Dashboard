# Phase 3: KPI・危険検知・売上分析(実データ計算)

## 目的
DBの実データからKPI・危険案件・売上推移を計算し、ホームと売上分析画面に表示する。

## 計算(`server/metrics.js`)
- `kpis` … 受注額(受注日)・請求額(発行日)・入金額(入金日)・期日超過の未回収・商談件数・見積提出数・契約待ち・開発中・稼働エンジニア数
- `detectRisks` … 納期遅延・未回収・未請求・商談滞留(しきい値は設定画面で変更可)
- `monthlySales` … 受注/請求/入金の月次推移(3/6/12ヶ月)
- `pipeline` … 商談ステージ別の集計

## API・画面
- `/api/metrics` `/api/metrics/sales` を追加
- ホームにKPIカード・危険案件・売上サマリー・営業パイプライン
- 売上分析画面(SVGチャート `public/js/charts.js` + テーブルビュー)

## 完了条件
- KPI・危険検知・売上推移がすべて実データから算出される
- しきい値変更が危険検知に反映される
