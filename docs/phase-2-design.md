# Phase 2: 案件・商談 CRUD とホーム画面

## 目的
案件(プロジェクト)と商談(ディール)の登録・編集・タスク管理を実装し、社長が毎朝見るホーム画面に「今日やること(最大3件)」を出す。

## データモデル(`server/db.js`)
- `projects` … 案件(顧客名・金額・ステータス・納期など)
- `project_tasks` … 案件内タスク(期限・完了フラグ)
- `project_events` … 案件のタイムライン(状態変化・メモ)
- `deals` … 商談(顧客・金額・ステージ・見込み)
- `deal_activities` … 商談の活動履歴

## API(`server/api.js`)
- `/api/projects` `/api/projects/:id`(CRUD・詳細=タスク/イベント/請求/メールを同梱)
- `/api/projects/:id/tasks`(タスク追加・完了)
- `/api/deals` `/api/deals/:id`(CRUD・ステージ更新)
- 商談を「受注」ステージにすると案件を自動作成(入力作業の自動化)

## ホーム画面(`public/js/app.js`)
- 「今日やること」= 未完了タスク + 契約待ち商談を、期限と金額で優先度スコアリングし**上位3件のみ**表示(`server/metrics.js` の `todayTasks`)
- 案件一覧・商談一覧・各詳細画面のルーティング

## 完了条件
- 案件・商談・タスクのCRUDが動作し、詳細画面に反映される
- 受注商談から案件が自動生成される
- ホームに優先タスクが最大3件表示される
