# VTaBridge OS - CEO Dashboard

社長が**毎朝5分**で会社の状況と最優先タスクを把握し、AIによる意思決定支援を受けられるダッシュボード。
(設計書 v1.0 に基づく実装)

## 起動方法

ビルド不要の静的Webアプリです。

```bash
# 任意のHTTPサーバーで配信(例)
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

`index.html` をブラウザで直接開いても動作します。

## 画面構成(設計書 §画面設計)

| 画面 | URL | 内容 |
|---|---|---|
| ホームダッシュボード | `#/home` | 今日やること(最大3件)・危険案件・売上サマリー・営業パイプライン・エンジニア稼働状況・AIからの提案・KPI |
| 案件一覧 | `#/projects` | ステータス絞り込み・検索・リスク表示 |
| 案件詳細 | `#/projects/:id` | 概要・請求/入金・タスク・タイムライン・危険検知 |
| 商談 / 商談詳細 | `#/deals` `#/deals/:id` | パイプライン・ステージ・次のアクション・活動履歴(CRM連携想定) |
| 売上分析 | `#/analytics` | 受注/請求/入金の月次推移・期間フィルタ・テーブルビュー・キャッシュフロー注意点 |
| AI議事録取込 | `#/minutes` | 議事録貼り付け → TODO自動抽出 → 案件登録 |
| 書類作成 | `#/documents` | 見積書・契約書・請求書のAIドラフト生成・印刷/PDF |
| AI秘書 | `#/assistant` | 経営データに基づくチャット応答 |
| 設定 | `#/settings` | 通知・連携・危険検知しきい値 |

## KPI(設計書 §KPI)

今日の優先タスク / 受注額 / 請求額 / 入金額 / 未回収金額 / 商談件数 / 見積提出数 / 契約待ち件数 / 開発中件数 / 稼働エンジニア数

## 設計原則(設計書 §設計原則)

- 社長に表示する優先タスクは**最大3件**
- API優先、API不可のみRPA
- AIは判断、RPAは入力
- 入力作業は極力自動化

## 実装メモ

- **依存ライブラリなし**(HTML / CSS / Vanilla JS のみ、ハッシュルーティングのSPA)
- チャートは軽量な自前SVG実装(クロスヘア+ツールチップ、凡例、直接ラベル、CVD検証済みパレット)
- ライト/ダークモード対応(`prefers-color-scheme`)
- データは `js/data.js` のモック。本番ではAPI経由で取得する想定(タスク完了状態・設定・議事録から登録した案件は `localStorage` に永続化)
- AI応答(秘書チャット・TODO抽出・書類ドラフト)はデモ用のルールベース実装。本番ではLLM APIに置き換える想定
